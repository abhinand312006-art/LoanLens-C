## Project Description
LoanLens is a menu-driven C application that helps users calculate loan EMI, view monthly loan repayment schedules, compare loan offers, and understand the effect of one-time prepayment.

## How to Run
1. Open the source file `main.c`.
2. Compile using a C compiler.
3. Run the generated program.
4. Select an option from the menu.

## Features
1. EMI Calculation
2. Monthly Amortisation Schedule
3. Comparison of Up to Three Loan Offers
4. One-Time Loan Prepayment
5. Input Validation
